# Student Management System

A Student Management System built using Flask and Python.

## Features
- Add Student
- View Students
- Update Student Details
- Delete Student Records

## Technologies Used
- Python
- Flask
- HTML
- CSS
- PostgreSQL

## Project Structure

```
Student-Management-System/
│── app.py
│── static/
│── templates/
```

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/anushgowdamh-bit/Student-Management-System.git
   ```

2. Go to the project folder:
   ```
   cd Student-Management-System
   ```

3. Install Flask:
   ```
   pip install flask
   ```

4. Run the application:
   ```
   python app.py
   ```

5. Open your browser and visit:
   ```
   http://127.0.0.1:5000
   ```
